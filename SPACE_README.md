# Echolyx AI — Fan Anomaly Detector

Proof-of-concept demo: upload or record a ~10 s fan recording for an instant
Normal vs. Faulty readout with confidence. See the main repo
(https://github.com/hassanimtiaz158/echolyx-MVP) for methodology,
limitations, and training details (PRD.md / TDD.md).

This is a research prototype, not a production monitoring system.
